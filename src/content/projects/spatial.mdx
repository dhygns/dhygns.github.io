## Overview

Spatial is a cross-platform metaverse for collaboration, gallery hosting, and creator commerce. As an early member I helped set up the architecture and contributed across most of the development surface.

## My role

- Built interactive 3D environments for the web app using Three.js (spatial.io)
- Developed cross-platform AR/VR clients on Unity3D for Oculus, Magic Leap, NReal, HoloLens 1/2
- Wrote real-time visual effects and custom shaders inside Unity's rendering pipeline
- Owned features end-to-end across SDLC — requirements, system design, implementation, automated testing, deployment, maintenance

## Coverage

Featured at TED Vancouver. Available across Oculus / Magic Leap / HoloLens / NReal / mobile / web.
