## Overview

Ambient Mode turns the QLED / The Frame / Terrace TV into part of the room when not in use — showing decoration, weather, photos, or the wall behind it. The "invisible" pattern feature captures the wall with a phone, then uses image processing and texture synthesis to fill the screen so the TV appears transparent.

## My role

Implemented Ambient Mode and generative art experiences for Tizen OS using OpenGL ES, Three.js, and WebGL. Designed and implemented the texture synthesis prototype (later adopted in *Disappearing Act* at Samsung First Look 2018).

## Techniques

- Texture synthesis from a single photographed sample
- Color calibration + brightness balancing for varying ambient light
- WebGL/OpenGL ES dual-stack for embedded TV deployment
